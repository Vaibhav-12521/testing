🌟 What Makes This Stand Out From Generic Projects
🧠
Subject-Aware Prompting
Auto-detect domain (CS, Biology, Law) and use subject-specific prompt templates. Biology = conceptual, CS = code-tracing, Law = case-based Q&A.
📐
Bloom's Taxonomy Levels
Generate cards at "Remember", "Understand", "Apply" levels. A slider lets students pick depth. Most projects only generate recall-level cards.
🔄
Real SM-2 Spaced Repetition
Implement the actual SuperMemo SM-2 algorithm (same as Anki). Track intervals, ease factor, repetitions per card. Not just a random quiz.
📦
Export Real .apkg Files
Export to genuine Anki .apkg format using genanki library. Students can import directly into Anki. No other student project does this.
🎯
Duplicate Detection
Use sentence-transformers to compute cosine similarity. If a generated card is too similar to an existing one, auto-discard it. Clean decks only.
📊
Learning Analytics Dashboard
Track retention rate, forgotten cards, study streaks, weak topics. Show a heatmap calendar and topic-wise accuracy graph.
🔌
Dual LLM Mode
Switch between Gemini (cloud) and Ollama/Llama 3 (offline). Demonstrate privacy-first architecture — your data never leaves the machine in offline mode.
🏷️
Auto-Tagging & Clustering
LLM assigns topic tags. Cards auto-cluster into sub-decks. Study "Chapter 3 only" or "All thermodynamics cards". Makes huge decks manageable.

⚗️ Core Prompt Template (v3 — Production-Ready)
System Prompt
You are an expert educational content designer. Your task: convert study notes into {count} high-quality flashcards. Rules: - Questions must be specific, not vague - Answers must be concise (1-3 sentences max) - Cover the most important concepts first - Difficulty: {level} (remember/understand/apply) - Subject domain: {subject} Return ONLY valid JSON. No markdown, no preamble. Format: { "cards": [ { "q": "...", "a": "...", "hint": "...", "topic": "...", "difficulty": 1-3 } ] }
User Prompt
Here are the study notes: <<<NOTES>>> {chunked_notes} <<</NOTES>>> Generate {count} Anki-style Q&A flashcards from the above. Focus on: {focus_topics_if_any} Avoid duplicating questions about: {existing_questions}
🎯 Subject-Specific Prompt Adapters
CS / Programming
Generate code-tracing cards where possible. For algorithms: ask about time complexity, not just definitions. Format code in the answer using backticks. Example Q: "What does this snippet output: for i in range(3): print(i*2)"
Biology / Medicine
Prefer questions that test mechanism understanding over recall. Use "What happens when..." and "Why does..." phrasings. Connect causes to effects (e.g., enzyme → substrate → product).
Law / Social Sciences
Generate scenario-based cards: "In case X, which legal principle applies?" Include case names or examples in the answer where relevant. Distinguish between similar concepts using comparison cards.
💡 Prompt Engineering Techniques Used
  • Structured output forcing — Strict JSON schema prevents hallucinated formats
  • Few-shot examples — 2–3 example cards in the prompt for the model to mimic
  • Negative prompting — "Avoid duplicating questions about: {existing}" prevents redundancy
  • Chain-of-density — Multi-pass: first pass extracts topics, second pass generates cards per topic
  • Temperature tuning — 0.3 for factual subjects, 0.7 for application-level cards
